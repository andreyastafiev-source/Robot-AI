# Robot AI: запуск после перезагрузки компьютера

> Программа автоматически проверяет имя `robot-ai.local`, а затем резервный
> адрес `192.168.0.18`. В компьютерной панели показываются готовая ссылка и
> QR-код для телефона. Телефон и компьютер должны быть в одной Wi-Fi сети.

## Что должно быть включено

1. Включите питание робота ESP32-CAM.
2. Убедитесь, что робот и компьютер подключены к одной Wi-Fi сети.
3. Текущий адрес робота: `192.168.0.18`.

## Проверка связи

Откройте PowerShell и выполните:

```powershell
ping 192.168.0.18
Test-NetConnection 192.168.0.18 -Port 80
Test-NetConnection 192.168.0.18 -Port 81
```

Порт 80 используется для команд, порт 81 — для камеры. Если IP изменился,
посмотрите новый адрес в Serial Monitor Arduino IDE (скорость 115200) и
обновите `DEFAULT_ROBOT_IP` и `DEFAULT_CAMERA_URL` в `core/config.py`.

## Запуск веб-панели

### Запуск ярлыком

Дважды щёлкните ярлык `Robot AI` на рабочем столе. Откроются окно сервера и
веб-панель. Не закрывайте окно сервера во время работы.

### Запуск через PowerShell

```powershell
cd C:\Users\user\Desktop\RobotAI
.\.venv\Scripts\Activate.ps1
python web_app.py
```

Не закрывайте это окно PowerShell. Откройте в браузере:

```text
http://127.0.0.1:8000
```

Для открытия панели с другого устройства в той же сети используйте IP
компьютера, например `http://192.168.0.10:8000`. Брандмауэр Windows может
попросить разрешить доступ Python к частной сети.

## Ручной режим

- `Вперёд`, `Назад`, `Влево`, `Вправо` запускают соответствующее движение.
- Повторное нажатие активной кнопки останавливает робота.
- `Стоп` всегда останавливает робота.
- Нажатие другого направления сразу заменяет текущую команду.
- Если панель перестала отвечать, watchdog останавливает робота примерно через
  три секунды.

При обнаружении животного робот останавливается, включает подсветку, сохраняет
фотографию, выключает подсветку и восстанавливает актуальную команду оператора.
После фотографии распознавание приостанавливается на три секунды.

Фотографии находятся в:

```text
C:\Users\user\Desktop\RobotAI\photos\ГГГГ-ММ-ДД
```

## Автоматический режим

Нажмите `Автоматический`. При смене режима сначала отправляется команда `stop`,
после чего запускается существующая автономная логика. Для возврата нажмите
`Ручной`; робот также сначала остановится.

## Завершение работы

Рекомендуемый вариант:

1. Нажмите внизу панели `Завершить программу`.
2. Подтвердите завершение. Сервер сначала отправит `stop`, выключит подсветку и
   корректно завершится.
3. Закройте вкладку браузера и окно сервера, если оно осталось открытым.
4. Выключите питание робота.

Варианты остановки из окна сервера:

- нажмите `Ctrl+C`;
- если не помогло, нажмите `Ctrl+C` повторно;
- из другого PowerShell выполните:

```powershell
Get-Process python -ErrorAction SilentlyContinue | Stop-Process
```

Последняя команда принудительно завершает все процессы Python. Используйте её,
только если другие Python-программы сейчас не работают. После принудительного
завершения отдельно убедитесь, что робот физически остановлен.

## Если панель не открывается

```powershell
cd C:\Users\user\Desktop\RobotAI
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python web_app.py
```

## Если камера не отображается

Проверьте поток напрямую:

```powershell
curl.exe --connect-timeout 5 --max-time 10 `
    http://192.168.0.18:81/stream `
    --output NUL
```

Также можно открыть `http://192.168.0.18:81/stream` в браузере.

## Проверка подсветки

Откройте последовательно:

```text
http://192.168.0.18/light/on
http://192.168.0.18/light/off
```

Оба запроса должны вернуть `OK`.
